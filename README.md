## 🚀 Tentang Project
Meowcing adalah landing page modern yang dirancang khusus untuk para anabul (anak bulu) dan pemiliknya. Dibuat dengan cinta menggunakan:
- **HTML5 & CSS3**
- **Tailwind CSS** (via CDN)
- **Google Fonts (Poppins)**
- **Nginx** (sebagai Web Server)
- **Let's Encrypt SSL** (keamanan HTTPS)

## ✨ Fitur Utama
- **Desain Responsif:** Tampilan yang cantik di HP, Tablet, maupun Laptop.
- **Warna Ceria:** Tema oranye & putih yang ramah dan hangat.
- **Struktur Rapi:** Dilengkapi navigasi, hero section, fitur, dan footer.
